# Alen Mathew Portfolio

A fast, editorial one-page portfolio website designed as an index to Alen's Behance case studies.

## Fastest way to make it live

### Option 1 — Vercel
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Vercel and create a new project from that GitHub repository.
4. Deploy.
5. Add the client's custom domain in Vercel → Project Settings → Domains.

### Option 2 — Netlify Drop
Drag the entire `alen-portfolio` folder into Netlify Drop for an instant temporary URL.

## Editing
- Project names/links are in `index.html`.
- Burnt Alive is currently marked "Coming Soon".
- Replace its `<div class="project project-disabled">...</div>` with the same `<a class="project"...>` structure used by the other projects once the Behance URL is available.
- Colors and spacing are in `style.css` under `:root`.
